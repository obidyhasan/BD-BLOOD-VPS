# Deployment documentation

The maintained production runbook is [`HOSTINGER_VPS_DEPLOYMENT.md`](../HOSTINGER_VPS_DEPLOYMENT.md).

It covers Hostinger VPS provisioning, DNS, Docker installation, TLS bootstrap,
deployments, migrations, deliberate seeding, backups, restoration, monitoring,
updates, and rollback. Use [`HOSTINGER_VPS_DEPLOYMENT_CHECKLIST.md`](../HOSTINGER_VPS_DEPLOYMENT_CHECKLIST.md)
for the go-live checklist.
